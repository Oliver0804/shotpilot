# ShotPilot

**繁體中文** | [English](README.en.md)

用手機當虛擬攝影機，在簡易 3D 場景裡「假裝拍攝」，產出給 AI 影片生成用的運鏡素材（RGB＋深度影片＋鏡頭軌跡）。

## 範例：用色塊排好構圖，再交給 AI 畫

AI 圖像／影片模型很難只靠文字控制「誰站哪裡、鏡頭從哪個角度拍」。ShotPilot 的做法是先用簡單形狀把場景排出來
（每個顏色代表一種東西），拿手機找好機位，再把截圖（或匯出的 RGB／深度影片）當作參考圖，配一段說明顏色的提示詞交給 AI。
構圖、位置、透視、光影方向都會照著場景走。

### 製作流程

1. **排場景**：工具列「＋新增物件」加入人偶、方塊、球等，用顏色區分角色（例如綠＝狗屋、黃＝狗、黑＝箱子）。也可以從「範本」分頁一鍵套用場景、燈光、機位。
2. **找機位**：手機連上後轉動手機就是轉鏡頭，蹲下鏡頭會變低，雙指縮放調 FOV；或直接用「機位」範本。
3. **出圖**：
   - 靜態圖：截下手機畫面（或用 MCP 的 `screenshot`）當參考圖。
   - 影片：錄一段 take 或用記錄點產生「自動運鏡」，匯出 `rgb.mp4`、`depth.mp4`、`camera.json`，給 video-to-video、ControlNet depth、camera control 類模型使用。
4. **寫提示詞**：說明主體是誰，再逐一說「什麼顏色是什麼東西」、彼此的關係（站在上面、掛在肩上…）。

```
┌──── 手機 App（mobile）────┐            ┌──────── ShotPilot（desktop）────────┐
│ 陀螺儀＋重力 → 鏡頭角度       │   pose     │ 場景編輯器：形狀、人偶、燈光、GLB、環境     │
│ 垂直加速度 → 蹲下／站起       │ ─────────► │ PhoneCameraRig：驅動鏡頭、錄 take、記錄點   │
│ 雙搖桿、雙指縮放 FOV          │   JSON     │ 全局視角：視錐、軌跡、記錄點、子畫面         │
│ 錄製／記點／自動運鏡／回放    │ ◄───────── │ 匯出：RGB＋深度 mp4、camera.json            │
│ 全螢幕顯示串流畫面            │   JPEG     │ StudioApi（127.0.0.1:8766）◄── MCP ◄── AI  │
└──────────────────────────────┘            └────────────────────────────────────────────┘
        UDP 47011 廣播自動找 PC（iOS 需手動輸入 IP）      WebSocket :8765
```

## 目錄

| 路徑 | 說明 |
|---|---|
| `desktop/` | **ShotPilot** 桌面 App（Godot 4.7 專案，主場景 `studio/studio.tscn`） |
| `desktop/studio/` | 場景編輯器、匯出、記錄點、MCP 用 HTTP API、Live2D 風格主題 |
| `desktop/addons/phone_camera_rig/` | 可單獨用在任何 Godot 專案的插件（PhoneCameraRig、PhoneCamOverview、編輯器 Dock） |
| `desktop/demo.tscn` | 插件最小範例（不含編輯器） |
| `mobile/` | 手機端 Godot 專案；`ios_run.sh` 一鍵裝到 iPhone |
| `mcp/` | 讓 AI 控制 Studio 的 MCP 伺服器（見 `mcp/README.md`） |

## 快速開始

1. Godot 4.7 執行 `desktop`（或在編輯器開啟後按 F5）。
2. 手機：`mobile/ios_run.sh` 安裝（Android 用 Godot 匯出 APK），同一個 Wi-Fi 下連到 Studio 顯示的 `IP:8765`。
   - `ios_run.sh` 用 App Store Connect API key 自動簽章：在 `~/.config/shotpilot/asc-api.env` 定義 `ASC_KEY_ID`、`ASC_ISSUER_ID`、`ASC_KEY_PATH`，並用環境變數 `IOS_TEAM_ID`、`IOS_BUNDLE_ID` 換成自己的 Team／Bundle ID（`mobile/export_presets.cfg` 的 `app_store_team_id` 也要改）。
3. 轉動手機就是轉鏡頭；Studio 主視窗是固定的全局視角，右下角是手機看到的畫面。

## 手機操作

| 操作 | 效果 |
|---|---|
| 轉動手機 | 鏡頭角度（直拿＝直式鏡頭，橫拿自動切換座標系與畫面比例） |
| 蹲下／站起 | 鏡頭跟著降低／升高（垂直加速度積分，停住 0.25 秒後鎖定高度） |
| 左搖桿 | 前後左右移動（依鏡頭水平朝向） |
| 升降滑桿 | 上下移動 |
| 右搖桿 | 鏡頭水平轉、俯仰（疊加在陀螺儀上，不用真的轉身） |
| 雙指縮放（畫面空白處） | FOV：張開拉近、捏合拉遠（10°~110°），會錄進 take |
| ● 錄製 | 即時錄一段 take（位置、角度、FOV） |
| 記點 | 記下目前鏡頭（位置、角度、FOV） |
| 自動運鏡 | 依記錄點產生平滑運鏡並播放 |
| ▶ 回放 | 播放選取／最新的 take；回放期間手機看得到運鏡畫面，結束回到原位 |
| 清除點／歸零／暫停跟隨 | 清空記錄點／回到站姿並對齊朝向／暫時不跟隨（調整姿勢用） |

## Studio 操作

- **新增**：工具列「＋新增物件」— 方塊、球、圓柱、膠囊、圓錐、圓環、平板、牆、樓梯、人偶、點光源；「匯入模型」載入 .glb/.gltf
- **變換模式**：W 移動／E 旋轉／R 縮放（工具列也有按鈕），**雙擊物件**在移動與旋轉間切換
  - 移動：左鍵拖物件＝水平移動、Shift＝上下、拖彩色箭頭＝沿軸
  - 旋轉：拖彩色圓環，開吸附時每 15° 一格；`[` / `]` 水平轉 15°
  - 縮放：拖方塊端點＝單軸，拖中心點＝等比
- **尺寸**：右側面板直接輸入寬／高／深（公尺）
- **自動放在下方物件上**（預設開）：水平移動時高度自動貼合腳下的物件或地板，可直接疊放；手動調高度會自動關閉
- **移動路線**：選物件 → 屬性面板「移動路線」→「在場景中點選新增路徑點」，模式可選單次／循環／往復，可設速度與「面向前進方向」。工具列「▶ 物件動畫」預覽；**錄製、回放、匯出時物件與鏡頭自動同步**（同一時間點畫面完全一致）
- **視角**（混合 Blender / Maya / Unity 習慣）：
  - 右鍵拖曳環繞、中鍵或 Shift+右鍵平移、滾輪縮放（拉到底會往前推進）
  - Alt+左／中／右鍵＝環繞／平移／推拉（Maya、Unity）
  - 右鍵按住＋WASD 飛行、Q/E 下降上升、Shift 加速（Unity、Unreal、Godot 編輯器）
  - 觸控板：雙指滑動環繞、Shift+雙指平移、捏合或 ⌘+雙指縮放
  - F 或數字鍵盤 . 把選取物件放滿畫面（沒選就對準手機鏡頭）、A 或 Home 看全部
  - 1／3／7 前／右／上視角（⌘ 反方向）、5 切換透視／正交（主鍵盤、數字鍵盤都可以）
  - 視角拖曳開始後游標移到側邊面板上也不會中斷
- **拖曳物件**：拖曳中按住 ⌘ 暫時反轉吸附；按 Esc 或右鍵取消並回到原位；只點選不移動不會產生復原步驟
- **快捷鍵**：Delete 刪除、⌘D 複製、⌘Z/⇧⌘Z 復原重做、⌘S 存檔、⌘O 開啟、⌘N 新場景、Q／Esc 取消選取、Esc 結束路徑點選、[ ] 旋轉 15°
- 新場景、開啟、關閉視窗前，有未儲存的修改會先詢問
- **範本分頁**
  - 場景：空白攝影棚、客廳、街道巷口、辦公室、公園、走廊、舞台（物件＋燈光＋機位一次換好，可 ⌘Z）
  - 燈光：晴天正午、黃昏斜陽、清晨薄霧、陰天、夜晚、攝影棚、綠幕
  - 機位：特寫、中景、全身、大遠景、低角度仰拍、高角度俯拍、側面、過肩、鳥瞰（以選取物件或人偶為主角，可勾「同時記點」快速排運鏡）
- **環境分頁**：太陽高度／方位／亮度／顏色、陰影、天空或純色背景、環境光、霧、地板
- **鏡頭／錄影分頁**：手機連線、FOV、「把鏡頭放到目前視角」、手感、記錄點與自動運鏡、take 清單、匯出
- 場景（含 take、記錄點、物件路線）存成 JSON，預設在 `文件/ShotPilot/scenes`

## 給 AI 影片的輸出

選一個 take →「匯出選取的 take」，離線逐幀渲染（不受即時效能影響），輸出到 `文件/ShotPilot/exports/<場景>_<take>_<時間>/`：

| 檔案 | 用途 |
|---|---|
| `rgb.mp4`（勾「保留 PNG」才另存 `rgb/00001.png…`） | 一般畫面（video-to-video 的結構參考） |
| `depth.mp4`（同上 `depth/00001.png…`） | 深度圖，近白遠黑，最遠距離可調（ControlNet depth 等） |
| `camera.json` | 每幀鏡頭位置、四元數、FOV（camera control 類模型可用） |

需要 ffmpeg 才會合成 mp4（`brew install ffmpeg`），沒有就只輸出 PNG 序列。畫面直接以管線送進 ffmpeg，不會先寫一堆 PNG；單段上限 10 分鐘，硬碟剩不到 2 GB 會自動停止。

## 讓 AI 控制（MCP）

```bash
claude mcp add shotpilot -- python3 /path/to/shotpilot/mcp/shotpilot_mcp.py
```

AI 可以讀場景、擺物件、調環境、設鏡頭、記點產生自動運鏡、截圖（編輯視角或鏡頭畫面）確認、匯出影片。詳見 `mcp/README.md`。

## 需求

- Godot 4.7（桌面端與手機端都是 Godot 專案）
- ffmpeg（匯出 mp4 用，`brew install ffmpeg`）
- Python 3.10+（MCP 伺服器，只用標準庫）
- iOS 16+ 或 Android 手機，與電腦在同一個區網

## 已知限制

- **水平位置**沒有絕對追蹤（加速度計積分幾秒就飄），所以用搖桿；只有垂直方向（蹲下／站起）用加速度計，誤差約 10~20%，可用「高度靈敏度」微調。真正的 6DoF 走動需要 ARKit／ARCore 外掛（協定已預留，可之後加）。
- **水平朝向**沒有絕對參考，長時間會慢慢漂，按「歸零」重新對齊。
- iOS 收不到 UDP 廣播（需 Apple 的 multicast entitlement），第一次要手動輸入 IP，之後會記住；第一次啟動要允許「區域網路」權限。
- 串流是 JPEG over WebSocket，區網延遲約 50–100 ms；網路塞住時 PC 會丟幀而不是累積延遲。

## 通訊協定

手機 → PC（文字 JSON）
```json
{"t":"pose","q":[x,y,z,w],"a":[ax,ay,az],"dt":0.016,"j":[mx,my],"l":[lx,ly],"v":lift,"f":false,"aspect":0.46}
{"t":"fov","v":35.0}
{"t":"cmd","c":"recenter|rec|waypoint|auto|play|clear_wp|undo_wp"}
```
PC → 手機：二進位＝JPEG 畫面；文字 `{"t":"state","p":[...],"fov":50,"rec":false,"rec_t":0,"playing":false,"wp":3}`（10 Hz）。

主題字型：jf-openhuninn（粉圓，OFL 授權，`fonts/jf-openhuninn-OFL.txt`）。
